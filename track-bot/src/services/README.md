# Services Directory

This directory contains utility services that can be integrated into the bot:

## UserService (`userService.ts`)
- User management and authentication
- Get/create users based on Telegram ID
- User validation and activation/deactivation
- Currently not integrated but available for future use

## AuditService (`auditService.ts`)
- Comprehensive audit logging system
- Tracks user actions, authentication events, and data access
- Provides monitoring and debugging capabilities
- Currently not integrated but available for future use

## ShipmentParser (`shipmentParser.ts`)
- Currently integrated and used in the main bot
- Parses shipment messages from providers
- Handles automatic shipment creation

Note: These services are ready for integration when needed for enhanced functionality.
